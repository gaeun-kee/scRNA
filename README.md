## Requirements
Experiments were conducted in **Python 3.8** with the following dependencies:

- TensorFlow 2.8.0  
- Keras 2.8.0  
- NumPy 1.22.1  
- Scikit-learn 1.1.0  
- XGBoost 1.7+  

To install all dependencies:
```bash
pip install -r requirements.txt
```
